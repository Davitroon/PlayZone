## 💡 About the Project

PlayZone was developed by a team of three students as a project for a Higher National Diploma in Web Development. The goal was to create a simple, fast, and entertaining gaming experience, applying responsive design principles and agile development methodologies.

---

## 🕹️ Available Games

PlayZone currently includes three minigames:

* **Quiz:** A question-and-answer game to test your knowledge.
* **Trios:** A memory challenge based on card matching.
* **Guerrillas:** [Short description of the game's dynamic].

---

## 🚀 Key Features

* **Fully Responsive Design:** Adaptable to mobile, tablet, and desktop devices thanks to **Bootstrap**.
* **Simple User Experience (UX):** Intuitive interface focused on immediate fun.
* **Collaborative Development:** Project managed under **Scrum** methodology with documentation in **Notion**.
* **Professional Design:** UI prototypes and mockups created in **Figma**.

## ⚙️ Installation

To try PlayZone on your local machine, follow these simple steps:

```bash
# Clone the repository
git clone https://github.com/SergioGMunoz/playzone.git

# Navigate to the project folder
cd playzone

# Open index.html directly in your browser and enjoy!
```
